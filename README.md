# bsc-compress-then-explain
As part of the *Warsztaty Badawcze* course, we initiated research focused on various modifications of the original **Compress Then Explain** method presented in the paper *Efficient and Accurate Explanation Estimation with Distribution Compression* by Hubert Baniecki, Giuseppe Casalicchio, Bernd Bischl, and Przemysław Biecek, 2025.
